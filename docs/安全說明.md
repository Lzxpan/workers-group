# 安全說明

打工人集團（Workers Group）採取「先驗證、再寫入」的安裝方式，目的是避免公開專案安裝時意外改掉你原本的 Codex 設定。

## 安裝邊界

安裝程式的來源固定在本專案 `package/` 下的五個公開安裝內容（payload）位置。它只接受公開技能（global skill）、共用靜態資料（static data）、五個角色設定（agent profiles）、掛鉤入口（hook entrypoint）和 Workers Group 的掛鉤設定（hooks manifest）。

程式拒絕 `__pycache__`、`.git`、`runtime`、`backups` 等目錄，也拒絕不在公開清單內的副檔名。這可降低把暫存資料、版本控制資料或二進位檔帶入全域目錄的風險。

## 保護既有設定

`config.toml` 不會被整份覆寫。若檔案不存在，安裝程式會建立最小的 UTF-8 設定，只包含 `hooks = true`、`multi_agent = true` 與 `max_threads = 4`。若檔案存在，程式只會合併這三個 Workers Group 必要設定並保留其他內容，且先建立備份（backup）。

對於將被更新的 Workers Group 檔案，程式會先在 `.codex/backups/workers-group-install/` 建立備份（backup）。這包括技能、靜態資料、角色設定、Hook 入口與原本的 `hooks.json`。

## 掛鉤合併規則

掛鉤（Hook）是 Codex 在特定生命週期事件執行的命令。安裝程式只合併命令列含有 `WG-HOOK-xxx` 的 Workers Group handler，不會移除或改寫其他工具的 Hook。

如果全域 `hooks.json` 沒有同一個 `WG-HOOK-xxx`，程式才會新增它。如果已存在且內容完全相同，程式保持原樣。如果內容不同，程式會停止並顯示衝突訊息；它不會猜測哪一份正確，也不會覆寫你的設定。

## 你可以先預演

使用 PowerShell 7 的預演（WhatIf）模式可先確認路徑與預計複製的檔案：

```powershell
pwsh -NoProfile -File .\scripts\install-global.ps1 -WhatIf
```

預演不會寫入檔案。不論預演或實際安裝，JSON（JavaScript Object Notation）格式錯誤、缺少必要公開檔案、或 Hook 衝突都會停止流程。

## 範圍與限制

安裝程式只保護檔案層級的安裝與 Hook 合併，不會證明 Codex 已在你的電腦成功載入技能或執行 Hook。請在實際使用的 Codex 版本中重新啟動並觀察行為；若有問題，使用成功訊息列出的備份進行人工還原。
