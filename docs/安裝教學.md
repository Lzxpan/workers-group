# 安裝教學

這份工具會把公開的打工人集團（Workers Group）檔案安裝到你的使用者層級 Codex 設定位置。它不會以整份範本覆寫 `config.toml`，也不需要系統管理員權限。

## 安裝前準備

請先安裝 PowerShell 7，並確認 `pwsh` 可在終端機執行。也請安裝可正常執行的 Codex。安裝程式只處理本專案 `package/` 中已公開的安裝內容（payload）；不會讀取或上傳你的提示、工作區、權杖或帳號資料。

下載本專案後，在專案根目錄執行：

```powershell
pwsh -NoProfile -File .\scripts\install-global.ps1
```

預設安裝位置是 `C:\Users\你的帳號\.codex`。若你的 Codex 使用其他位置，可以明確指定：

```powershell
pwsh -NoProfile -File .\scripts\install-global.ps1 -CodexHome 'D:\CodexHome'
```

想先只看預計動作、不寫入任何檔案，可使用預演（WhatIf）：

```powershell
pwsh -NoProfile -File .\scripts\install-global.ps1 -WhatIf
```

## 安裝後會做什麼

安裝程式只會處理下列公開檔案：

- 全域技能（global skill）：`package/global-skill/` → `.codex/skills/orchestrating-workers-group/`
- 共用靜態資料（static data）：`package/workers-group-static/` → `.workers-group/`
- 角色設定（agent profiles）：`package/global-agents/` → `.codex/agents/`
- 掛鉤入口（hook entrypoint）：`package/hooks/workers_group_hook.py` → `.codex/hooks/`
- 掛鉤設定（hooks manifest）：`package/hooks/workers-group-hooks.json` 合併進 `.codex/hooks.json`

在覆寫上述既有 Workers Group 檔案前，程式會建立備份（backup）。成功訊息會列出備份位置，預設格式為 `.codex/backups/workers-group-install/時間戳記/`。

若沒有 `config.toml`，程式會建立最小的 UTF-8 設定：`[features]` 下的 `hooks = true`、`multi_agent = true`，以及 `[agents]` 下的 `max_threads = 4`。若檔案已存在，只會合併這三個必要設定，保留其餘內容。

## 安全停止規則

`config.toml` 不會被整份覆寫。程式只會建立最小設定，或在既有檔案中合併三個 Workers Group 必要設定；變更前會備份既有檔案。

安裝前會先完整檢查公開安裝內容（payload）與 `workers-group-hooks.json`。如果全域 `hooks.json` 已有同一個 `WG-HOOK-xxx`，但內容與公開版本不同，程式會直接停止，不會覆寫，也不會開始複製檔案。請先保留你的版本、比較差異，再由人工決定後續處理方式。

同樣地，若公開安裝內容（payload）出現不允許的檔案類型或目錄，安裝會停止。這是為了避免把暫存檔、執行期資料或非公開內容帶進全域設定。

## 確認安裝

重新開啟 Codex 後，可在新工作階段直接提出需要多人分工的具體任務。打工人集團會依任務範圍使用規劃（Planner）、執行（Executor）、專案管理（PM）與獨立驗證（QA）角色。

這個檢查只確認安裝程式已完成檔案處理；不同版本的 Codex 是否載入 Hook，仍要以實際啟動時的行為為準。

## 解除安裝與還原

每次 fresh 安裝會建立解除安裝收據（receipt）：`.codex/workers-group-install-receipt.json`。要移除這次安裝的 Workers Group，請在專案根目錄執行：

```powershell
pwsh -NoProfile -File .\scripts\uninstall-global.ps1
```

它會先比對所有受管理檔案的 SHA-256 雜湊（SHA-256 hash）。若內容與安裝完成時不同、檔案遺失或備份遺失，程式會停止且不做任何變更。這避免還原時覆寫你後來的修改。

fresh 安裝建立的 Workers Group 檔案會被移除；安裝前已存在的 Workers Group 檔案會從備份還原。它不會遞迴刪除目錄，也不會刪除或覆寫不在收據內的 Codex、Hook、角色設定或 `config.toml` 內容。

同樣可先預演：

```powershell
pwsh -NoProfile -File .\scripts\uninstall-global.ps1 -WhatIf
```

## 如果解除安裝停下來

不要手動把備份檔複製回去，也不要直接刪除整個 `.codex` 資料夾。前者可能蓋掉你後來的設定，後者會刪掉你自己的其他 Skill、Hook 和設定。

請保留畫面上的錯誤訊息與備份資料夾，再比較你後來修改的檔案；確定要捨棄自己的修改後，才由熟悉 Codex 設定的人協助處理。
