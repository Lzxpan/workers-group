INSTALL ONCE, USE EVERYWHERE

安裝一次，任何專案都能叫出團隊。

先用安全預演（WhatIf）看安裝器預計做什麼；確認後再正式安裝。

pwsh -File .\scripts\install-global.ps1 -WhatIf pwsh -File .\scripts\install-global.ps1 $orchestrating-workers-group
